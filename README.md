# Frete Fácil

Projeto acadêmico desenvolvido para a consulta de CEP e cálculo estimado de frete utilizando uma API pública.

## Sobre o projeto

O sistema permite informar um CEP para consultar os dados do endereço, calcular a distância aproximada entre a UNINASSAU Parangaba e o destino e apresentar uma estimativa de valor para o frete.

## 🔗 Acesso o projeto

https://dev-hillary.github.io/simulador-de-frete/

## Funcionalidades

* Consulta de CEP por API pública
* Exibição do endereço encontrado
* Cálculo aproximado da distância
* Estimativa de valor do Uber Moto
* Cálculo do valor estimado do frete

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* API pública de CEP

## Objetivo acadêmico

Projeto desenvolvido para colocar em prática conceitos de HTML, CSS, JavaScript, APIs públicas e cálculos utilizando dados de localização.

## Observação

Os valores apresentados são estimativas utilizadas exclusivamente para fins educacionais.
